一、它是什么

白话

Prime Agent 是一个开源的编码和研究智能体。它的特别之处在于：不是"给你一个 AI 助手"，而是"给你一个会自我进化的 AI 助手"——它能用 Python 代码创建子 Agent、能在工作中复盘并改进自己的行为方式。

两大核心抽象：

  1. RLM（递归语言模型）：把"提示词"当变量，把"子 Agent"当函数调用——在持久 REPL 里，用代码编排 Agent 网络
  2. Continual Harness（持续装备）：提示词、记忆、技能、子 Agent 配置存为持久状态，Agent 可以小步改进它们

二、为什么突然爆火

❌ 传统 Agent

你一句我一句对话
工具是"插件"
每次会话从零开始
不会自己变强

✅ Prime Agent

编程式编排 Agent 网络
一切皆代码（IPython）
状态持久，跨会话保留
/refine 自我改进

爆火原因

行业共识是"Agent 的差距在技能不在模型"。Prime Agent 把这一点做到了极致：Agent 自己写技能、自己创建子 Agent、自己复盘改进——它不只是用技能的 Agent，而是会制造技能的 Agent。

三、核心特性

特性说明
一切皆代码持久 IPython 是内建工具：文件、shell、子Agent、上下文全通过 Python
rlm(...) 创建子Agent像调函数一样创建真实子 Agent，并行/后台执行并拿回结果
/refine 自我改进复盘工作轨迹，小步更新记忆/技能/子Agent配置，可回滚
技能即代码技能是可导入的 Python 包，可自动把重复工作流变成技能
后台守护运行终端断开 Agent 继续跑，可随时重连（daemon 架构）
Agent 间直连运行中的 Agent 互相发现、互发消息、互相编排
长任务不死自动上下文压缩、持久目标、心跳、定时唤醒、自主模式

五、安装与使用

安装（macOS/Linux 一行）：

curl -fsSL https://app.primeintellect.ai/prime-agent/install.sh | sh

常用命令：

# 交互模式 prime-agent # 单次问答 prime-agent -p "你的问题" --provider opencode-go --model deepseek-v4-flash # 会话管理 prime-agent agents # 浏览运行中的会话 prime-agent attach # 重连会话 prime-agent --resume # 恢复保存的会话 prime-agent status # 后台服务状态
配置模型

支持 30+ 提供商：OpenAI、DeepSeek、Gemini、Claude、Groq，以及原生支持 OpenCode Go（用 `OPENCODE_API_KEY` 环境变量）。用户实测：OpenCode Go 会员额度可直接驱动。

七、安全提示

⚠️ 重要

Prime Agent 会以你的用户权限执行模型生成的 Python 代码。worker/kernel 进程提供生命周期隔离和恢复，但不是安全沙箱。官方建议：

  • 使用可丢弃的克隆/工作树（方便回滚）
  • 只运行可信的仓库、指令、技能和扩展
  • 不可信代码放到外部沙箱执行
